專題二企劃書：情緒垃圾車 Emotion Garbage Truck

Emotion Garbage Truck: A Cathartic Interactive Trash Truck

版本：v3.0（完整狀態邏輯版）

類型：趣味互動裝置 / 情緒設計專題

核心一句話：一台只能倒「壞情緒」的垃圾車，用搖桿選出「ㄍㄢˋ」「ㄎㄠˋ」「ㄘㄠˋ」三種情緒，丟進去、銷毀、然後聲音隨垃圾車遠去。

技術棧：ESP32 + Velxio + FastAPI + MySQL + Web 動畫 + 無源蜂鳴器

硬體：ESP32、HW504 搖桿、無源蜂鳴器、LCD1602 I2C、單顆 LED

⚠️ 能力邊界聲明：本裝置為情緒宣洩的象徵性互動，不是心理治療工具，不提供醫療建議。若情緒困擾持續，請尋求專業協助。

第一章：專題概述

1.1 設計動機

現代人每天線上線下遇到很多煩心瑣事和垃圾情緒。這些情緒不能隨便對人發洩，又不能一直憋著。與其讓情緒爛在心裡，不如丟進垃圾車。

1.2 三種情緒

注音情緒日常對應
ㄍㄢˋ憤怒遇到鳥事、被惹毛
ㄎㄠˋ不爽被雷到、無言
ㄘㄠˋ煩躁事情太多、卡住

第二章：設計哲學

情緒不是垃圾，是養分。

垃圾車不是終點，是循環的起點。情緒被清運後，會變成化糞池的養分，滋養植物、動物，長出一個美麗的世界。

人做決策，機器做執行。

第六章：bags 生命週期

6.1 完整流程

【新的一天開始】
dailyCollectCount = 0
bags = 0
    │
    ▼
【IDLE】
    │ 使用者確認一個情緒
    ▼
bags += 1
    │
    ├── bags < 5 → IDLE
    └── bags = 5 → FULL
    │
【FULL】
    │ 清運時間到
    ▼
【APPROACHING】bags 不變
    │ 音樂完成
    ▼
【ARRIVED】bags 不變
    │ 旋轉 3 圈
    ▼
【THROW_READY】bags 不變
    │ 按下 SW
    ▼
【THROWING】bags 不變
    │ 自動
    ▼
【RESPONDING】
    ├── 小心：bags = max(0, bags - 5)
    ├── 謝謝：bags = max(0, bags - 5)
    └── 回收：removed = random(1, 5)，不超過 bags
               bags -= removed
    │
    ▼
【COLLECTED】不修改 bags
    │ dailyCollectCount++
    │
    ├── < 2 → IDLE（繼承剩餘 bags）
    │
    └── = 2 → REST_DAILY_LIMIT
              │
              ├── 如果 bags > 0：
              │   LCD 顯示「垃圾已被好心清理乾淨」
              │   bags = 0
              │
              └── 隔天：
                  dailyCollectCount = 0
                  bags = 0
                  → IDLE

第十一章：清運次數與跨日規則

11.1 清運次數

項目規則
變數uint8_t dailyCollectCount = 0;
增加時機只在 COLLECTED 結束時
增加次數每次 +1
判斷count < 2 → IDLE；count ≥ 2 → REST_DAILY_LIMIT
清零時機新的一天（日期變更）
不增加的狀態APPROACHING、ARRIVED、THROW_READY、THROWING、RESPONDING

11.2 跨日規則

情境行為
跨日bags 不保留到隔天
當天第 2 次清運還有剩餘 bags顯示「垃圾已被好心清理乾淨」，bags = 0
隔天dailyCollectCount = 0，bags = 0，進入 IDLE

11.3 測試期間重置

指令效果
resetdailyCollectCount = 0，bags = 0，進入 IDLE
