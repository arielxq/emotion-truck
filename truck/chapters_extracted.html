第一章：專題概述

1.1 設計動機

現代人每天線上線下遇到很多煩心瑣事和垃圾情緒。這些情緒不能隨便對人發洩，又不能一直憋著。與其讓情緒爛在心裡，不如丟進垃圾車。

真實世界的垃圾車有固定的時間、固定的音樂、固定的規則，還有隨機的工作人員互動。本專題把「倒垃圾」這個日常行為，轉化成「倒情緒」的儀式：

  • 垃圾車音樂響起 → 提醒你「可以倒垃圾了」
  • 用搖桿選出情緒 → 把壞情緒「打包」
  • 螢幕顯示垃圾袋被拋棄、銷毀 → 象徵性情緒釋放
  • 工作人員隨機提示 → 有時順利收走，有時被退還
  • 音樂逐漸模糊消失 → 垃圾車開走了，情緒也走了

1.2 為什麼選這三種組合

注音情緒日常對應
ㄍㄢˋ憤怒遇到鳥事、被惹毛
ㄎㄠˋ不爽被雷到、無言
ㄘㄠˋ煩躁事情太多、卡住

三種就夠了。真實的垃圾車也只收三種垃圾：一般垃圾、資源回收、廚餘。情緒垃圾車也一樣，三種情緒，三種出口。

1.3 v2.5 核心修正：改用傳統四腳 RGB LED

原本設計v2.5 修改
WS2812 RGB LED（1 GPIO）傳統四腳 RGB LED：R、G、B、GRD
RGB LED 閃爍模擬震動保留閃爍作為視覺回饋，不宣稱是真實震動
合計 7 GPIO合計 9 GPIO

控制邏輯：

  • R/G/B 三個腳位 → 由 ESP32 分別控制三色亮度與混色
  • GRD 公共腳 → 接 ESP32 GND；本企劃使用共陰極四腳 RGB LED
  • 閃爍節奏 → 作為視覺化回饋，不等同於實際震動

好處：元件容易取得、三色控制直觀，且可使用 PWM 做出不同亮度與狀態效果。相較 WS2812，需增加兩個 GPIO。

第二章：時間規則與待機提示

2.1 時段狀態總表

時段狀態螢幕顯示音樂搖桿
開放時段（9:00–20:00）非播放時間待機「垃圾車還沒來」無無效
開放時段（9:00–20:00）播放時間到達「垃圾車來了！」播放中有效
非開放時段（20:00–9:00）休息「垃圾車休息中」無無效
週三、週日（全天）休息「垃圾車休息中」無無效

2.2 兩種待機提示的區別

提示出現時機含義
「垃圾車還沒來」開放時段內，但不在隨機播放時間今天會來，但還沒到，情緒先放著
「垃圾車休息中」非開放時段，或週三/週日今天不會來，明天再倒

2.3 時段判斷邏輯

讀取當前時間
    │
    ├── 是週三或週日？ → 顯示「垃圾車休息中」
    │
    ├── 時間 < 09:00 或 > 20:00？ → 顯示「垃圾車休息中」
    │
    ├── 在隨機播放時間內？ → 顯示「垃圾車來了！」
    │
    └── 其他（開放時段但非播放時間）→ 顯示「垃圾車還沒來」

2.4 隨機播放時間

規則說明
開放時段每天 09:00–20:00
隨機播放每天隨機 2 次
播放間隔兩次間隔至少 3 小時
播放時長每次約 3–5 分鐘
休息日週三、週日全天不播放

2.5 收垃圾間隔規則

規則說明
最小間隔兩次收垃圾間隔至少 10 分鐘
計算方式從上一次「確認收走」的時間開始算
間隔內按搖桿顯示「垃圾車剛走，請稍等」

正式模式不可調整、不可重置

7.1 硬體清單

硬體用途標記
ESP32主控已實作
搖桿 HW504方向選擇 + 確認已實作
LCD1602 或 OLED顯示狀態、日期時間、情緒已實作

7.2 引腳佔用（v2.5 四腳 RGB LED）

硬體GPIO備註
搖桿 X 軸1ADC
搖桿 Y 軸1ADC
搖桿按鍵1數位
LCD1602 (I2C)2SDA/SCL
蜂鳴器1PWM
RGB LED R1PWM，建議 GPIO 26
RGB LED G1PWM，建議 GPIO 32
RGB LED B1PWM，建議 GPIO 33
RGB LED GRD0共陰極公共腳接 GND
合計9不包含 GND；比 WS2812 方案多 2 個 GPIO

注意：本企劃改用共陰極傳統四腳 RGB LED。R、G、B 各接一個具有限流電阻的 GPIO，GRD 接 ESP32 GND。若實際使用共陽極版本，公共腳需改接 3.3V，且程式的 PWM 邏輯需要反相。

7.3 RGB LED 的顏色與閃爍角色

角色呈現方式對應狀態
顏色指示綠/橙/黃/紅待機/選擇/收走/退還
閃爍節奏短閃/長閃/連續閃視覺化互動回饋，不代表實際震動

閃爍節奏對照表：

節奏閃爍模式含義對應場景
不閃常亮待機待機狀態
單次短閃亮 200ms短震搖桿確認
雙次短閃亮 100ms ×2已收到送出情緒
連續閃爍亮 200ms ×5連續震退還提醒
長閃亮 1s長震緊急狀態

9.4 工作人員提示映射（後端）

import random

WORKER_PROMPTS = [
    {"sound": "CAREFUL", "text": "小心",   "result": "COLLECTED", "weight": 50,
     "led": {"color": "GREEN", "pattern": "DOUBLE_BLINK"}},
    {"sound": "THANKS",  "text": "謝謝",   "result": "COLLECTED", "weight": 25,
     "led": {"color": "GREEN", "pattern": "DOUBLE_BLINK"}},
    {"sound": "RECYCLE", "text": "這是回收哦", "result": "RETURNED",  "weight": 25,
     "led": {"color": "RED",   "pattern": "BLINK_FAST"}},
]

def pick_worker_prompt():
    total = sum(p["weight"] for p in WORKER_PROMPTS)
    r = random.uniform(0, total)
    upto = 0
    for p in WORKER_PROMPTS:
        upto += p["weight"]
        if r <= upto:
            return p
    return WORKER_PROMPTS[0]

11.2 垃圾車接近與離開的音量效果

階段旋律效果實作方式
接近 APPROACHINGToelise 主旋律逐漸清晰、明亮由低音量／低密度開始，逐段增加播放音量或音符密度
到達 ARRIVEDToelise 主旋律循環最清晰、最明亮維持設定音量，等待互動
離開 DEPARTINGToelise 主旋律逐漸淡化、消失逐段降低音量或播放密度，結束後停止蜂鳴器

硬體限制：無源蜂鳴器不像喇叭具有真正的音量控制，因此以 PWM duty、播放密度、音符間隔與逐段停止的方式近似「由遠到近」及「由近到遠」。
